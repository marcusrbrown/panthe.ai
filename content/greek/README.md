# content/greek

Authored Greek content pack.
`world/` holds locations, rules, buildings, and inhabitants.
`gods/` holds one sourced profile per god (Zeus, Hera, Athena, Hermes, Hephaestus, Poseidon, and Hades); each profile must match a deity inhabitant in `world/inhabitants.json`.
A mortal's `devotion` names the god it prays to first and the affinity it starts with.
See [lore/README.md](lore/README.md) for the sourcing rule.
